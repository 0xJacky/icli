- `app kill`, `app running`, `app frontmost` and `app launch` find an app that is still running after its package was upgraded. dpkg replaces the bundle while the old process runs on, and that process has no executable path any more, so icli could not match it: `app kill --force` answered `already_stopped` while the app kept running, `app running` left it out, and `app frontmost` fell back to SpringBoard, which made `app launch` report `app did not become frontmost` with the app on screen. A process without a path now counts when RunningBoard says it is that app. Tested on iOS 15.8.6 with Dopamine (rootless) and an iOS 26.6.2 vphone with RootHide.
