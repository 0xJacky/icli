- `app register`, `app refresh`, `sb uicache` and installs no longer stall on an app whose `PlugIns` folder holds something other than an app extension: a resource bundle, a framework, or an `.appex` without `NSExtension`. LaunchServices registers only extensions there and drops the rest without an error, on iOS 26 and 27 alike, while icli's read-back expected every entry, so the comparison never matched: each registration then listed every installed app ten times and the refresh ended in `0 failed, 1 unverified`. On a phone with many apps that took tens of seconds. icli now registers only app extensions, as LaunchServices keeps them, and reads back the one app it registered instead of every app. The field-by-field comparison from 0.7.17 stays.
- A refresh that ends in `refresh_incomplete` names what LaunchServices did not record and for which app, for example `LaunchServices did not record the plug-ins of /var/jb/Applications/Example.app`, instead of counting failed and unverified apps.
- A screenshot taken through the render server, used when UIKit cannot capture the screen, is no longer black. It now requires every IOSurface function it uses and returns no image otherwise.
- `app launch ""` reports `app not found` instead of reaching an app whose bundle identifier is empty.
